01 / VALIDATION

IMEI ফরম্যাট যাচাই

শুধু নিজের বা অনুমোদিত ডিভাইসের নম্বর পরীক্ষা করুন।

Luhn উত্তীর্ণ হওয়া ডিভাইসের সত্যতা, TAC বরাদ্দ, মালিকানা বা ব্ল্যাকলিস্ট স্ট্যাটাস প্রমাণ করে না। ইনপুট ব্রাউজারেই যাচাই হয়।

02 / REFERENCE

IMEI-এর গঠন

TAC8Type Allocation Code
SNR6Serial Number
CD1Luhn check digit

সাধারণ IMEI ১৫ ডিজিট: TAC ৮ + serial ৬ + check digit ১। একাধিক SIM slot-এ আলাদা IMEI থাকতে পারে।

ডিভাইসে দেখার উপায়

  • ডায়ালার: *#06#
  • Android: Settings → About phone → IMEI / Status
  • iPhone: Settings → General → About
  • প্যাকেজিং/ক্রয়রসিদ/অনুমোদিত সার্ভিস রেকর্ডের সঙ্গে তুলনা করুন।
